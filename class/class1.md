### 0.3 C 와 C++ 의 관계

- C++ 는 C 를 **거의 그대로 포함**합니다. C 코드는 대부분 C++ 에서도 그대로 컴파일됩니다.
- 그래서 이 수업은 **"C 로 하던 것을 C++ 에서는 어떻게 하는가"** 를 비교하며 진행합니다.

| C | C++ | 무엇이 좋아지나 |
|---|-----|-----------------|
| `#include <stdio.h>` | `#include <iostream>` | 자료형에 맞는 출력이 자동으로 된다 |
| `printf("%d\n", n);` | `cout << n << endl;` | 형식 지정자를 틀릴 일이 없다 |
| `scanf_s("%d", &n);` | `cin >> n;` | `&` 를 빠뜨릴 일이 없다 |
| `int* p = &a;` | `int& r = a;` | 포인터 없이 원본을 다룰 수 있다 |
| `malloc / free` | `new / delete` | 생성자·소멸자가 자동 호출된다 (ex3) |
| 없음 | `bool` | 참/거짓을 나타내는 전용 자료형 |

## 1. C++ 의 첫 프로그램

### 1.1 Hello!

```cpp
#include <iostream>
using namespace std;

int main()
{
	cout << "Hello!" << endl;
}
```

**예상 출력**
```
Hello!
```

| 요소 | 설명 |
|------|------|
| `#include <iostream>` | 입출력(input/output stream) 기능을 쓰기 위한 헤더. C 의 `<stdio.h>` 자리 |
| `cout` | **c**onsole **out**put. 화면에 출력하는 **객체** |
| `<<` | 출력 연산자. "왼쪽으로 흘려보낸다" 는 느낌 |
| `endl` | **end l**ine. 줄바꿈(`\n`) + 출력 버퍼 비우기 |
| `using namespace std;` | `std::` 를 매번 붙이지 않게 해 주는 선언 |

### 1.2 `using namespace std;` 를 쓰지 않으면

```cpp
#include <iostream>

int main()
{
	std::cout << "Hello!" << std::endl;
}
```

- `cout`, `endl` 은 사실 **`std` 라는 이름 공간(namespace)** 안에 들어 있습니다.
- `using namespace std;` 는 "std 안의 이름들을 그냥 써도 된다" 는 선언입니다.
- namespace 는 **[class2.md](class2.md)** 에서 자세히 다룹니다.

## 2. cout 은 자료형을 가리지 않는다

### 2.1 여러 자료형 출력하기

```cpp
#include <iostream>
using namespace std;

int main()
{
	// cout : ostream 객체
	// <<   : ostream 출력 연산자
	// endl : '\n' 출력 + 버퍼 비우기
	cout << 100 << endl;
	cout << 5.5 << endl;
	cout << 'A' << endl;
	cout << "Hello!" << endl;
}
```

**예상 출력**
```
100
5.5
A
Hello!
```

**C 와 비교해 보세요**

```c
printf("%d\n", 100);      // 정수는 %d
printf("%f\n", 5.5);      // 실수는 %f
printf("%c\n", 'A');      // 문자는 %c
printf("%s\n", "Hello!"); // 문자열은 %s
```

- C 에서는 **자료형마다 다른 형식 지정자**를 외워야 하고, 틀리면 이상한 값이 나옵니다.
- C++ 의 `<<` 는 **컴파일러가 자료형을 보고 알아서** 맞는 출력 방식을 고릅니다.

---

### 2.2 `<<` 를 연결해서 한 줄로 출력하기

```cpp
#include <iostream>
using namespace std;

int main()
{
	cout << 100 << " " << 5.5 << " " << 'A' << " " << "Hello!" << endl;
}
```

**예상 출력**
```
100 5.5 A Hello!
```

- `<<` 는 몇 번이든 이어 붙일 수 있습니다.
- 왜 이어 붙일 수 있는지는 **[class13.md](class13.md)** 에서 `operator<<` 를 직접 만들어 보며 이해합니다.

---

### 2.3 주소와 형변환 결과 출력하기

```cpp
#include <iostream>
#include <cstdio>
using namespace std;

int main()
{
	int n = 100;

	cout << &n << endl;        // 주소
	cout << n << endl;         // 값
	cout << (int)'A' << endl;  // 65
}
```

**예상 출력** (주소는 실행할 때마다 달라집니다)
```
000000B59F37FB14
100
65
```

- `&n` 을 넣으면 **주소를 16진수로** 출력해 줍니다. (`printf` 의 `%p` 에 해당)
- `(int)'A'` 처럼 형변환을 하면 문자 `'A'` 의 아스키 코드 `65` 가 출력됩니다.

> **`<cstdio>` 란?**
> C 의 `<stdio.h>` 를 C++ 방식으로 포함하는 헤더입니다.
> C++ 에서는 C 헤더 이름 앞에 `c` 를 붙이고 `.h` 를 떼는 것이 규칙입니다.
> `stdio.h` → `cstdio`, `string.h` → `cstring`, `stdlib.h` → `cstdlib`

## 3. cin 으로 입력받기

### 3.1 기본 입력

```cpp
#include <iostream>
using namespace std;

int main()
{
	int n;
	cin >> n;
	cout << "int: " << n << endl;
}
```

**실행 예 (10 을 입력)**
```
10
int: 10
```

| 요소 | 설명 |
|------|------|
| `cin` | **c**onsole **in**put. 키보드 입력을 담당하는 객체 |
| `>>` | 입력 연산자. "오른쪽 변수로 흘려 넣는다" 는 느낌 |

**C 와 비교**

```c
int n;
scanf_s("%d", &n);   // & 를 빼먹으면 프로그램이 죽는다
```

- `cin >> n;` 은 **`&` 가 필요 없습니다.** 변수의 형식도 자동으로 파악합니다.
- `&` 를 빼먹어 생기는 흔한 실수가 사라집니다.

---

### 3.2 C 의 scanf_s 와 함께 쓰기

```cpp
#include <iostream>
#include <cstdio>   // C의 <stdio.h> 를 C++ 방식으로 포함
using namespace std;

int main()
{
	int n;
	cin >> n;

	int b;
	scanf_s("%d", &b);
	cout << "int: " << n << "," << b << endl;
}
```

**실행 예 (10 과 20 을 입력)**
```
10
20
int: 10,20
```

- C++ 안에서 C 의 입출력 함수도 **그대로 쓸 수 있습니다.**
- 다만 두 방식을 섞으면 버퍼가 꼬일 수 있으므로, 실무에서는 **한 가지로 통일**하는 것이 좋습니다.

## 4. 변수 초기화 3가지 형식

```cpp
#include <iostream>
using namespace std;

int main()
{
	int a = 100;   // C 스타일 복사 초기화
	int b(100);    // 직접 초기화
	int c{ 100 };  // 중괄호 초기화 (C++11)

	cout << a << endl;
	cout << b << endl;
	cout << c << endl;
}
```

**예상 출력**
```
100
100
100
```

| 형식 | 이름 | 특징 |
|------|------|------|
| `int a = 100;` | 복사 초기화 | C 에서 쓰던 방식. 가장 익숙하다 |
| `int b(100);` | 직접 초기화 | 클래스 객체를 만들 때 자주 쓴다 (`Point pt(2,3);`) |
| `int c{ 100 };` | 중괄호 초기화 | **값이 잘리면 컴파일 에러**를 내 준다 (가장 안전) |

```cpp
int x = 3.9;     // 경고만 나고 3 이 들어간다
int y{ 3.9 };    // X - 에러 : 값이 잘리므로 컴파일이 막힌다
```

- 세 번째 형식은 **실수를 컴파일 단계에서 잡아 준다**는 점이 장점입니다.
- 클래스를 배우면 `( )` 형식이 **생성자 호출**과 이어진다는 것을 알게 됩니다. ([class4.md](class4.md))

## 5. 참조자(reference) - C++ 의 새 무기

### 5.1 값 복사 vs 참조

```cpp
#include <iostream>
using namespace std;

int main()
{
	int a = 10;
	int b = a;   // 복사 : b 는 새로운 저장 공간
	int& c = a;  // 참조 : c 는 a 의 다른 이름

	cout << a << ',' << b << ',' << c << '\n';
	cout << &a << ',' << &b << ',' << &c << '\n';  // &a 와 &c 가 같다
}
```

**예상 출력** (주소는 실행할 때마다 달라집니다)
```
10,10,10
00000034F1D5F784,00000034F1D5F7A4,00000034F1D5F784
```

- `b` 는 **새 상자**입니다. 주소가 다릅니다.
- `c` 는 **a 라는 상자에 붙인 두 번째 이름표**입니다. 주소가 `a` 와 완전히 같습니다.

```
        a                    b
      ┌──────┐             ┌──────┐
c ──▶ │  10  │             │  10  │
      └──────┘             └──────┘
      주소 ...784           주소 ...7A4
```

---

### 5.2 포인터와 참조자를 나란히 비교하기

```cpp
#include <iostream>
using namespace std;

int main()
{
	int a = 10;
	int* p = &a;   // 포인터 : 주소를 담는 변수
	int& r = a;    // 참조자 : 변수의 또 다른 이름

	cout << a << ',' << *p << ',' << r << endl;
	cout << &a << ',' << p << ',' << &r << endl;
}
```

**예상 출력**
```
10,10,10
000000B59F37FB14,000000B59F37FB14,000000B59F37FB14
```

| 비교 항목 | 포인터 `int* p` | 참조자 `int& r` |
|-----------|-----------------|-----------------|
| 선언 | `int* p = &a;` | `int& r = a;` |
| 값을 읽을 때 | `*p` (역참조 필요) | `r` (그냥 쓴다) |
| 나중에 다른 곳 가리키기 | 가능 (`p = &b;`) | **불가능** |
| `nullptr` 가능 여부 | 가능 | **불가능** (항상 대상이 있다) |
| 초기화 없이 선언 | 가능 (`int* p;`) | **불가능** |
| 실제 사용처 | 동적 메모리, 배열 순회 | **함수 매개변수, 반환값** |

**참조자의 핵심 장점** : `*` 를 붙일 필요가 없어서 **코드가 원본을 다루는 것처럼 자연스럽게** 읽힙니다.

---

### 5.3 참조자는 선언할 때만 대상을 정할 수 있다

```cpp
#include <iostream>
using namespace std;

int main()
{
	int a = 10;
	int& r = a;   // 초기화 시에만 참조 할당 가능!!!

	int& rr;      // X - 에러 : 참조자는 반드시 초기화해야 한다
	rr = a;
}
```

**컴파일 에러**
```
error C2530: 'rr': 참조를 초기화해야 합니다.
```

- 참조자는 **"이름표"** 이므로, 붙일 대상 없이 이름표만 만들 수는 없습니다.
- 한 번 붙인 이름표를 **다른 변수로 옮길 수도 없습니다.**

```cpp
int a = 10, b = 20;
int& r = a;
r = b;        // 주의! r 이 b 를 가리키게 되는 게 아니라, a 에 b 의 값(20)이 대입된다
cout << a;    // 20
```

> 이것이 참조자를 처음 배울 때 가장 헷갈리는 부분입니다. **`r = b;` 는 "r 을 b 로 바꾼다" 가 아니라 "a 에 20 을 넣는다"** 입니다.

---

### 5.4 참조자로 원본 바꾸기

```cpp
int a = 10;
int& r = a;

r = 20;              // 참조자를 바꾸면 원본 a 가 바뀐다
cout << a << endl;   // 20
```

- 이 성질 때문에 참조자는 **함수 매개변수**로 쓰일 때 진가를 발휘합니다. ([class2.md](class2.md) 의 `Swap`)

## 6. bool 자료형

```cpp
#include <iostream>
using namespace std;

int main()
{
	bool b = true;

	if (b)
		cout << "true" << endl;

	cout << b << endl;      // 1 로 출력
	cout << false << endl;  // 0 으로 출력
}
```

**예상 출력**
```
true
1
0
```

| 항목 | 설명 |
|------|------|
| `bool` | 참(`true`) 또는 거짓(`false`) 만 담는 자료형 |
| 크기 | 1바이트 |
| 출력 | 기본적으로 `1` / `0` 으로 출력된다 |
| `true`/`false` 로 출력하려면 | `cout << boolalpha << b;` |

- C 에서는 `int` 에 0 과 1 을 넣어 참/거짓을 흉내 냈지만, C++ 는 **전용 자료형**이 있습니다.
- `if`, `while` 의 조건식과 비교 연산자(`==`, `<` 등)의 결과가 모두 `bool` 입니다.

## 7. 완성 코드 (ex1.cpp 맨 위)

```cpp
#include <iostream>
using namespace std;

int main()
{
	int a = 10;
	int* p = &a;   // 포인터    : 주소를 담는 변수
	int& r = a;    // 참조자    : 변수의 또 다른 이름(별명)

	bool b = true; // C++ 의 참/거짓 자료형

	cout << a << ',' << *p << ',' << r << endl;   // 값   : 셋 다 10
	cout << &a << ',' << p << ',' << &r << endl;  // 주소 : 셋 다 같은 주소

	r = 20;        // 참조자를 바꾸면 원본 a 가 바뀐다
	cout << a << endl;

	if (b)
		cout << "true" << endl;
	cout << b << endl;      // 1
	cout << false << endl;  // 0
}
```

**예상 출력**
```
10,10,10
000000B59F37FB14,000000B59F37FB14,000000B59F37FB14
20
true
1
0
```

## 8. 정리 표

| 주제 | 내용 |
|------|------|
| 헤더 | `#include <iostream>` (C 의 `<stdio.h>` 자리) |
| namespace | `using namespace std;` 를 쓰면 `std::` 생략 가능 |
| 출력 | `cout << 값 << endl;` — 자료형을 가리지 않는다 |
| 입력 | `cin >> 변수;` — `&` 가 필요 없다 |
| C 헤더 사용 | `<stdio.h>` → `<cstdio>`, `<string.h>` → `<cstring>` |
| 초기화 3형식 | `int a = 1;` / `int b(1);` / `int c{1};` |
| 중괄호 초기화 | 값이 잘리면 **컴파일 에러** → 가장 안전 |
| 참조자 선언 | `int& r = a;` — 반드시 초기화, 나중에 못 바꿈 |
| 참조자 vs 포인터 | 참조자는 `*` 불필요, `nullptr` 불가, 재지정 불가 |
| `r = b;` 의 의미 | r 이 b 를 가리키는 게 아니라 **원본에 b 의 값이 대입** |
| bool | `true` / `false`, 출력은 `1` / `0` |
